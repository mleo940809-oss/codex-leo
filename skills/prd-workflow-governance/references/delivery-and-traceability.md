# Delivery and Traceability

## Delivery package

- The delivery package must match the frozen version exactly.
- Missing any required artifact means the package is incomplete.
- Delivery should include the PRD body, acceptance criteria, attachment list, and confirmation record when applicable.

## Prototype binding

- Formal prototypes need a binding record.
- The binding record should include the live prototype link, PRD version, prototype scope, source-file path, confirmer, confirmation time, and archive result.

## Archive and versioning

- Use explicit version numbers and handoff records.
- If a frozen document changes, treat the update as a formal change.
- Keep the relationship between the PRD, prototype, and archive records easy to audit later.
