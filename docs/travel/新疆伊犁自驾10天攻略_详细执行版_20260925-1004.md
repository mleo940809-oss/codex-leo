## 3. Day 1｜09-25｜深圳/广州/香港 -> 伊宁

**住宿**: 伊宁市  
**强度**: 低  
**原则**: 不赶路，完成取车和补给

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 09:00-16:00 | 珠三角出发，飞伊宁 | 优先深圳/广州直飞或低中转；晚到则压缩市区游玩 |
| 16:00-17:30 | 伊宁机场取车 | 拍车况视频，确认保险、备用胎、油量、还车规则 |
| 17:30-18:30 | 入住酒店，放行李 | 选伊宁市区或六星街附近 |
| 18:30-19:40 | 六星街 | 彩色街区、门头、咖啡馆、手工艺小店 |
| 19:50-21:00 | 喀赞其民俗区 | 蓝色民居、街巷、人文摄影 |
| 21:00-21:40 | 伊犁河大桥可选 | 看日落余光；晚点则取消 |
| 21:40-22:30 | 晚餐和补给 | 买水、零食、晕车药、纸巾，确认第二天油量 |

### 六星街怎么玩

1. 从主街入口进入，先拍彩色门窗和街巷透视。
2. 不要只在主路拍，往支路走 100-200 米，人少很多。
3. 选择一家咖啡馆或冰淇淋店短停 20 分钟，适应节奏。
4. 拍照重点：彩色墙面、门头、窗框、街角、手工艺小店外立面。

### 喀赞其怎么玩

1. 先走蓝色民居密集街巷，拍建筑和街道色彩。
2. 再选民俗院落或马车街巷体验，避免在商业摊位停太久。
3. 如果想拍人文，先征得对方同意。

### 当天备选

- 航班晚点到 20:00 后：直接取车、入住、晚餐，六星街移到 Day 10 或取消。
- 行李延误：先完成取车和入住，购买基础洗漱用品，第二天早上再处理。

## 4. Day 2｜09-26｜伊宁 -> 赛里木湖 -> 果子沟 -> 清水河/霍城

**住宿**: 清水河或霍城  
**强度**: 中  
**原则**: 赛里木湖是热门景点，必须作为当天第一个核心景点；早进景区，下午离开

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:30 | 伊宁出发 | 酒店早餐可打包，提前加满油 |
| 09:45 | 到赛里木湖东门 | 停车、买票、进景区 |
| 10:00-15:40 | 赛里木湖环湖 | 约 5.5 小时，东门进，优先顺时针或按景区当日交通规则执行 |
| 15:40-16:20 | 松树头/南门方向 | 看体力决定是否爬高位观景点 |
| 16:20-17:00 | 果子沟大桥观景 | 不在桥上违规停车，只去安全观景点 |
| 17:00-18:20 | 前往清水河/霍城 | 避免天黑后找酒店 |
| 18:30-20:00 | 入住、晚餐 | 复盘第二天伊昭公路开放情况 |

### 赛里木湖景区内游玩顺序

推荐采用“东门进、环湖、南门/东门出”的逻辑，具体以当日景区允许入口为准。公开攻略普遍建议自驾环湖预留 5-7 小时，环湖约 90 公里。

1. **东门入口**
   - 先不要在入口耗太久，上午光线更适合往湖边推进。
   - 完成洗手间、购票、导航设置。
2. **月亮湾 / 三台草原**
   - 适合第一组湖景照片。
   - 停留 20-30 分钟，不要过度消耗时间。
3. **亲水滩**
   - 重点拍湖水、雪山、公路、人物近景。
   - 停留 30-40 分钟，注意风大和湖边湿滑。
4. **北岸/点将台一带**
   - 适合拍开阔湖面和远山。
   - 如果当天风大，减少停留。
5. **西海草原**
   - 湖面、草地、雪山层次较好。
   - 午后适合慢走，但不要错过后半程。
6. **克勒涌珠**
   - 重点看不冻泉、湖边栈道、天鹅概率点。
   - 停留 30-40 分钟。
7. **金花紫卉 / 松树头方向**
   - 若体力好，松树头可爬高看湖；体力一般只在低位观景。
   - 9 月底风冷，爬高前加衣。
8. **南门/果子沟方向离开**
   - 离开后打卡果子沟大桥安全观景点。

### 当天删减规则

- 如果进景区已晚于 11:30：取消松树头爬高，只做环湖核心点。
- 如果大风或降雨：保留亲水滩、克勒涌珠、西海草原，其他点快速经过。
- 如果景区自驾票不可用：改乘区间车，优先选择能覆盖亲水滩、克勒涌珠、松树头的线路。

## 5. Day 3｜09-27｜清水河/霍城 -> 霍尔果斯可选 -> 伊昭公路 -> 昭苏

**住宿**: 昭苏县  
**强度**: 中高  
**原则**: 不绕回伊宁深玩，霍尔果斯只是可选短停；伊昭公路开放则走景观线，封闭则走常规线

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 08:00 | 清水河/霍城出发 | 前一晚确认伊昭公路状态 |
| 08:40-10:00 | 霍尔果斯口岸可选 | 对口岸无兴趣则直接跳过 |
| 10:00-12:30 | 向伊昭公路方向移动 | 中途加油、午餐简餐 |
| 12:30-17:30 | 伊昭公路景观段 | 山口、草原、河谷，安全点停车 |
| 17:30-18:30 | 抵达昭苏，入住 | 不建议当天去夏塔 |
| 18:30-20:00 | 昭苏县晚餐/草原日落 | 看天气决定是否去县城周边开阔处 |

### 伊昭公路怎么玩

1. **入口前加满油**，上路后不要把补给寄托在沿途小店。
2. **只在停车区或宽阔安全处停车**，不要在弯道、坡顶、窄路边停车拍照。
3. **游玩重点不是某一个景点，而是路上层次**：山口、草坡、雪山、牧场、河谷。
4. **拍照策略**：每 40-60 分钟最多停一次，单次 10-15 分钟，避免拖到天黑。

### 当天备选

- 伊昭公路封闭：走常规道路到昭苏，预计车程增加或风景下降，但安全性更高。
- 霍尔果斯排队/安检耗时超过 40 分钟：立即放弃，优先赶路。
- 午后天气变差：减少停车，确保 19:00 前入住昭苏。

## 6. Day 4｜09-28｜昭苏 -> 夏塔 -> 特克斯

**住宿**: 特克斯  
**强度**: 中高  
**原则**: 夏塔必须早进，下午离开，晚上到特克斯

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:30 | 昭苏出发 | 酒店早餐打包更稳 |
| 09:00 | 到夏塔景区 | 停车、购票、排队乘景交 |
| 09:30-10:30 | 景交/摆渡进入核心区 | 以景区当日线路为准 |
| 10:30-14:30 | 夏塔核心徒步和拍照 | 控制强度，不强行走太远 |
| 14:30-15:30 | 返回游客中心 | 预留排队时间 |
| 15:30-19:30 | 夏塔 -> 特克斯 | 中途休息一次 |
| 19:30-21:00 | 特克斯入住、晚餐 | 八卦城中心或离街散步 |

### 夏塔景区内游玩顺序

夏塔的内部交通和栈道会随年份、天气、维修调整，出发前以景区公告为准。当前公开攻略提示，部分旧打卡点可能调整，建议以景区摆渡终点和开放徒步线为核心。

1. **游客中心**
   - 先确认当天最远可到达位置、返程末班车、天气和步道开放情况。
   - 不要在游客中心购物耗时。
2. **摆渡车终点**
   - 下车后先拍第一组雪山远景。
   - 确认返程上车点，避免回来找不到。
3. **核心河谷步道**
   - 沿开放步道向雪山方向走，控制在单程 60-90 分钟。
   - 重点拍雪山、草甸、溪流、森林同框。
4. **青蛙泉/天空之镜方向可选**
   - 如果景区当日开放且体力允许，走 1-2 公里精华段。
   - 体力一般则不要继续深入。
5. **返回摆渡点**
   - 14:30 前开始回撤，避免下午排队和天气突变。

### 当天删减规则

- 10:30 后才进核心区：只走前半段步道，14:00 回撤。
- 下雨/下雪/大雾：不深入徒步，拍近景和森林，提前去特克斯。
- 同行人高反、头痛、明显疲劳：立即缩短线路。

1. **先草原线，不先峡谷线**
   - 上午光线和体力更适合草原。
   - 人体草原、草原曲线、雪山背景是重点。
2. **人体草原**
   - 找高低起伏的侧光角度，不要只在平台正面拍。
   - 停留 30-40 分钟。
3. **鲜花台/猎鹰台方向**
   - 9 月底花少，重点看草原起伏和远山。
   - 如果风大，缩短停留。
4. **阔克苏大峡谷**
   - 下午看峡谷线条更合适。
   - 重点停鳄鱼湾、峡谷观景台、河谷弯道。
5. **景区交通**
   - 喀拉峻内部交通耗时较长，不要临时加琼库什台。

### 当天备选

- 如果喀拉峻天气差：只玩阔克苏大峡谷，下午提前到巩留休整。
- 如果景区排队严重：放弃“草原 + 峡谷”双线，只保留草原线。
- 如果 17:30 仍未出景区：直接住特克斯或附近，不疲劳夜路去巩留。

---

## 8. Day 6｜09-30｜巩留 -> 恰西 -> 库尔德宁 -> 新源/那拉提

**住宿**: 新源或那拉提镇  
**强度**: 中  
**原则**: 森林河谷日，不塞热门大景区；晚上住到那拉提附近，为 Day 7 早进景区做准备

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 08:00 | 巩留出发 | 加油，准备山路驾驶 |
| 09:30-12:00 | 恰西 | 自驾慢看河谷、草地、森林 |
| 12:00-13:00 | 午餐/车上简餐 | 景区餐饮不稳定，建议自备 |
| 13:00-16:30 | 库尔德宁 | 云杉林、河谷、秋色 |
| 16:30-19:30 | 前往新源/那拉提 | 看住宿价格决定住哪里 |
| 19:30-20:30 | 入住、晚餐 | 确认那拉提门票、自驾票或区间车 |

### 恰西怎么玩

1. **不追求打满点位**，恰西适合开一段、停一段、看河谷。
2. **优先找开阔草地 + 云杉 + 河流组合**，9 月底秋色会比草色更重要。
3. **单次停车控制 10-20 分钟**，避免全天节奏被拖慢。
4. 如果道路泥泞或有施工，立即减少深入。

### 库尔德宁怎么玩

1. **先到核心观景区**，看雪岭云杉和河谷。
2. **选择一条轻步道走 40-60 分钟**，不做长徒步。
3. **拍照重点**：云杉林纵深、河谷开阔处、秋色林带、远山。
4. 16:30 前必须开始离开，否则到那拉提附近会太晚。

### 当天备选

- 恰西路况差：取消恰西，巩留直接去库尔德宁。
- 库尔德宁天气差：只做恰西 + 提前去新源休整。
- 那拉提住宿太贵：住新源，Day 7 提前 30-40 分钟出发。

---

## 9. Day 7｜10-01｜新源/那拉提 -> 那拉提景区

**住宿**: 那拉提镇或新源  
**强度**: 中  
**原则**: 国庆第一天，必须早进；那拉提是当天唯一大景区

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:30 | 新源/那拉提出发 | 若住那拉提镇，可 08:00 出发 |
| 08:00-08:30 | 到那拉提游客中心 | 停车、取票、确认线路 |
| 08:30-12:30 | 空中草原线 | 天界台、天牧台、游牧人家 |
| 12:30-13:30 | 午餐/休息 | 景区或镇上，按线路衔接 |
| 13:30-16:30 | 河谷草原或盘龙谷 | 买不到自驾票则区间车 |
| 16:30-18:30 | 二次补拍/返回 | 选择光线好的点补拍 |
| 18:30-20:00 | 回镇上晚餐 | 不赶夜路去巴音布鲁克 |

### 那拉提景区内游玩顺序

那拉提常见线路包括空中草原、河谷草原、盘龙谷等。公开攻略中空中草原线常见停靠天界台、天牧台、游牧人家；具体开放和自驾规则以景区当日为准。

1. **空中草原线优先**
   - 作为当天第一个线路，避开国庆人流。
   - 先到高位观景点看全景。
2. **天界台**
   - 俯瞰空中草原层次。
   - 停留 20-30 分钟。
3. **天牧台 / 游牧人家**
   - 拍草原、毡房、远山、人像。
   - 如果有骑马项目，控制在 30-60 分钟，不要影响下午线路。
4. **河谷草原**
   - 下午走更轻松，地势平缓，适合散步和补拍。
   - 重点看河流、草原、森林交织。
5. **盘龙谷可选**
   - 如果有自驾票且体力好，可用盘龙谷替代河谷草原。
   - 山路弯多，不适合疲劳驾驶。

### 当天删减规则

- 景区排队超过 1 小时：只保留空中草原线。
- 天气阴沉：空中草原减少停留，下午走河谷草原看近景。
- 自驾票买不到：不要纠结，区间车更稳。

## 10. Day 8｜10-02｜那拉提 -> 独库中段 -> 巴音布鲁克

**住宿**: 巴音布鲁克镇  
**强度**: 中  
**原则**: 上午确认独库是否开放；巴音布鲁克核心是九曲十八弯日落

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 08:30 | 那拉提出发 | 出发前查独库路况 |
| 08:30-12:30 | 独库中段转场 | 山路驾驶，安全停车拍照 |
| 12:30-13:30 | 巴音布鲁克镇午餐/入住寄存 | 先吃饭、补水、加衣 |
| 14:00-15:00 | 进入巴音布鲁克景区 | 乘景交进入核心区 |
| 15:00-16:20 | 天鹅湖/湿地 | 看季节，不执着天鹅数量 |
| 16:20-19:30 | 九曲十八弯 | 提前占观景位，等日落 |
| 19:30-21:00 | 返回镇上 | 晚餐、休息，准备 Day 9 早出 |

### 巴音布鲁克怎么玩

1. **先确认末班车和日落时间**
   - 九曲十八弯要提前到，不要卡点。
2. **天鹅湖/湿地**
   - 作为前半段轻游，停留 40-60 分钟。
   - 看不到天鹅很正常，不影响主体验。
3. **九曲十八弯**
   - 至少提前 1.5-2 小时到观景区域。
   - 选高位视角，带厚衣服，日落前风冷。
4. **日落后快速返程**
   - 人流集中，跟随景区交通，不要拖延。

### 当天备选

- 独库中段封闭：取消巴音布鲁克，改那拉提深玩或新源休整，Day 9 走伊宁/乌鲁木齐方向。
- 巴音布鲁克阴雨无日落：仍可看湿地和草原，但不要期待九曲高光，第二天早点出发。

---

## 11. Day 9｜10-03｜巴音布鲁克 -> 独库北段 -> 乔尔玛 -> 独山子 -> 乌鲁木齐

**住宿**: 乌鲁木齐  
**强度**: 高  
**原则**: 全程最累，必须早出发；独山子大峡谷是可选，不是硬任务

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 07:30 | 巴音布鲁克出发 | 带早餐，满油，查路况 |
| 07:30-12:30 | 独库北段前半程 | 山路、雪山、峡谷，安全停车 |
| 12:30-13:30 | 乔尔玛午餐/休息 | 乔尔玛纪念地短停 |
| 13:30-17:00 | 乔尔玛 -> 独山子 | 继续独库北段，控制停车次数 |
| 17:00-18:20 | 独山子大峡谷可选 | 天色晚或疲劳则取消 |
| 18:20-22:00 | 独山子 -> 乌鲁木齐 | 高速为主，入住休息 |

### 独库北段怎么玩

1. **核心是公路体验，不是堆景点**
   - 每 60-90 分钟休息一次。
   - 只在正规停车区、观景台、安全宽阔处停车。
2. **乔尔玛**
   - 午餐、洗手间、纪念地短停。
   - 停留 40-60 分钟即可。
3. **独山子大峡谷**
   - 只有在 17:00 前到达且司机不疲劳时进入。
   - 游玩 60-80 分钟，拍峡谷边缘、栈道、远景。
4. **不走夜间山路**
   - 如果独库上半段耗时过长，直接放弃独山子大峡谷。

### 当天备选

- 独库北段封闭：从巴音布鲁克经和静、托克逊方向去乌鲁木齐；如果耗时过长，中途住和静/库尔勒，返程航班改到 10 月 5 日。
- 司机疲劳：乔尔玛后减少所有停留，独山子大峡谷取消。
- 雨雪结冰：不强行走独库，按交警和路网提示改线。

## 12. Day 10｜10-04｜乌鲁木齐 -> 深圳/广州/香港

**住宿**: 无  
**强度**: 低  
**原则**: 返程日只做轻安排，航班优先

### 时间安排

| 时间 | 安排 | 说明 |
|---|---|---|
| 08:30-09:30 | 早餐、整理行李 | 检查证件、车内物品 |
| 09:30-10:30 | 还车前加油、洗车可选 | 按租车规则处理 |
| 10:30-11:30 | 机场/门店还车 | 拍还车视频，确认无新增车损 |
| 12:00-15:00 | 大巴扎或新疆博物馆可选 | 航班晚于 18:00 才建议安排 |
| 航班前 3 小时 | 前往机场 | 国庆返程安检和道路都要留余量 |

### 市区可选怎么玩

- **新疆国际大巴扎**：适合买伴手礼、干果、拍建筑外观，停留 1-1.5 小时。
- **新疆博物馆**：适合想看历史文化，需提前确认预约和开放时间，停留 1.5-2 小时。
- 航班早于 17:00：不安排市区游玩，直接还车去机场。

## 13. 关键预订和预约提醒

- **机票**：优先查“广州/深圳/香港 -> 伊宁”和“乌鲁木齐 -> 广州/深圳/香港”的开口组合。
- **租车**：必须确认伊宁取、乌鲁木齐还的异地还车费；SUV 优先。
- **住宿**：那拉提、巴音布鲁克、特克斯、昭苏优先订可取消房。
- **门票**：赛里木湖、那拉提、巴音布鲁克、夏塔、喀拉峻出发前 3-7 天复核预约规则。
- **路况**：伊昭公路、独库公路在 9 月底至 10 月初存在天气封闭风险，最终以新疆路网、交警、景区公告为准。
