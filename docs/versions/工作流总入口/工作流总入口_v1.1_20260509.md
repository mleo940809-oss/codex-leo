## 4. PRD 冻结前检查清单

如果当前任务要输出或冻结 PRD、高保真原型或交付包，先检查以下 4 项是否已经完成：

1. [PRD工作流复用模板.md](/E:/Codex/New_rules/docs/PRD工作流复用模板.md) 中的 `PRD-原型一致性矩阵`
2. [产品需求管理流程规范.md](/E:/Codex/New_rules/docs/产品需求管理流程规范.md) 中的 `PRD-原型一致性门禁`
3. [产品需求管理流程规范.md](/E:/Codex/New_rules/docs/产品需求管理流程规范.md) 中的 `高保真原型可交互门禁`
4. [PRD工作流复用模板.md](/E:/Codex/New_rules/docs/PRD工作流复用模板.md) 中的 `原型交互验收` 和 `需求交付包输出`

检查到位标准：

- 5.1.11 `PRD-原型一致性矩阵` 已完成并可追溯到功能点、场景、规则和异常
- 10.3 `原型交互验收` 已完成并可追溯到活链接、主路径、分支、异常和权限
- 10.4 `需求交付包输出` 已完成并可追溯到冻结版本、附件清单和确认记录

对应执行与验收路径：

- 5.1.11 `PRD-原型一致性矩阵` 由 [流程执行技能附录.md](/E:/Codex/New_rules/docs/流程执行技能附录.md) 的 PRD 章节路由负责
- 10.3 `原型交互验收` 由 [流程执行技能附录.md](/E:/Codex/New_rules/docs/流程执行技能附录.md) 的评审与确认路由负责
- 10.4 `需求交付包输出` 由 [流程执行技能附录.md](/E:/Codex/New_rules/docs/流程执行技能附录.md) 的评审与确认路由负责

## 5. PRD 模板选择

### 前期探索

使用 [PRD工作流复用模板.md](/E:/Codex/New_rules/docs/PRD工作流复用模板.md)。

适用场景：

- 需求受理
- 需求探讨
- 问题定义
- 范围收敛
- 方案草案

### 正式交付

使用 [standard-prd-template.md](/E:/Codex/New_rules/docs/standard-prd-template.md)。

适用场景：

- 正式评审
- 需求冻结
- 研发交付
- 测试验收
- 最终归档

### 切换规则

- 前期稿允许保留待确认项，但不得直接当作正式交付物。
- 进入正式评审、冻结或交付阶段时，必须切换到正式模板。
- 前期稿与正式稿不得混用同一文件反复覆盖。
