# 商品券活动管理 - 活动新增页设计稿

**文档版本**：V1.3  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动新增页  
**文档性质**：修订版，基于“两段式创建 + 公共区 / 差异区”结构，补充字段级校验规则

## 1. 设计目标

活动新增页用于创建新的商品券活动，从券类型选择开始，逐步完成活动基础信息和类型专属规则配置，最终生成待审核活动。

本页仅负责“从无到有”的创建流程，不承接生效前修订，也不承接生效后修改。Code 文件上传不属于本页职责，统一归入批次管理页。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. `SINGLE` 与 `UPLOAD` 均为系统固定属性，不作为用户选择项
5. 新建活动后进入审批流程，初始状态为 `AUDITING`
6. 新增页只负责创建，不负责已存在活动的修订
7. 新增流程采用“两段式”：
   - 第一步：选择券类型
   - 第二步：进入对应表单
8. 进入创建表单后，不允许切换券类型；如需切换，必须返回券类型选择页重新开始
9. 返回券类型选择页时，不保留当前已填内容
10. 允许保存草稿，且草稿以活动为单位保存
11. 每个活动同一时间只能有一个草稿
12. Code 文件上传属于批次管理页，不属于本页

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动新增页
- 页面职责：
  - 选择券类型
  - 创建新活动
  - 录入活动基础信息
  - 配置活动类型专属规则
  - 配置展示信息
  - 提交创建结果

## 4. 页面结构

建议新增页采用“两段式”结构：

### 4.1 券类型选择页

先选择：
- 满减券
- 兑换券

### 4.2 创建表单页

按信息层级分区展示：
1. 公共区
2. 差异区
3. 提交确认

## 5. 字段设计

### 5.1 公共区

公共区展示每种活动都一样的配置项。

| 字段 | 说明 | 是否必填 | 输入规则 / 展示规则 | 备注 |
|---|---|---:|---|---|
| 商品券名称 | 新建活动的名称 | 是 | 3-15 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行；首尾空格自动去除 | 用于列表和详情展示 |
| 商品券图片 | 商品券展示图片 | 是 | 仅支持通过图片上传能力获得的图片链接；推荐 1:1；建议尺寸 1080\*1080；大小不超过 2M；建议透明 PNG 格式；需保留上下左右 120px 透明边距 | 页面必填 |
| 商品券背景图 | 商品券背景图片 | 是 | 仅支持通过图片上传能力获得的图片链接；宽高比 65:77；建议尺寸 1170\*1326；大小不超过 2M；建议 JPG/PNG 格式；需保留商品名称与商品图安全区域 | 页面必填 |
| 商品券详情图 | 商品详情图列表 | 否 | 最多可上传 8 张；每张图片要求宽高比 65:77；建议尺寸 1170\*1326；大小不超过 2M；建议 JPG/PNG 格式 | 选填扩展项 |
| 商品券标题文案 | 页面展示标题 | 是 | 3-20 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行；首尾空格自动去除 | 用于列表摘要和活动详情展示 |
| 商品券副标题 | 辅助展示文案 | 否 | 0-30 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 可用于营销补充信息 |
| 规则摘要 | 前台可读规则概述 | 是 | 0-200 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 用于辅助理解活动内容 |
| 使用模式 | 固定值 `SINGLE` | 是 | 只读展示，不可修改 | 固定属性 |

说明：
- `使用模式` 为系统固定值，仅展示
- `商品券图片`、`商品券背景图`、`商品券名称`、`商品券标题文案`、`规则摘要` 为页面核心必填项
- `商品券详情图` 为选填扩展项

### 5.2 差异区

差异区只展示当前已选活动类型对应的专属字段。

#### 5.2.1 满减券差异区

| 字段 | 说明 | 是否必填 | 输入规则 / 展示规则 | 备注 |
|---|---|---:|---|---|
| 门槛金额 | 满减券触发门槛 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 例如满 100 元 |
| 减免金额 | 满减券减免金额 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 例如减 20 元 |
| 满减说明 | 满减券补充说明 | 否 | 0-100 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 选填扩展项 |

控制关系说明：
- `门槛金额` 与 `减免金额` 均为必填，且互不自动推导
- 两个金额仅做独立合法性校验，不做自动换算
- 若后端对金额存在额外限制，以提交时返回结果为准

#### 5.2.2 兑换券差异区

| 字段 | 说明 | 是否必填 | 输入规则 / 展示规则 | 备注 |
|---|---|---:|---|---|
| 商品原价 | 兑换内容对应原价 | 否 | 以元为单位输入；最多 2 位小数；输入范围 0 到 100000.00；不允许负数和字母 | 选填扩展项 |
| 适用商品组合 | 可兑换商品组合配置 | 是 | 至少配置 1 个组合；最多配置 50 个组合；每个组合需满足组合级校验 | 组合级字段见下文 |
| 兑换说明 | 兑换券补充说明 | 否 | 0-100 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 选填扩展项 |

##### 5.2.2.1 适用商品组合

“适用商品组合”为可重复配置区，每个组合至少包含以下字段：

| 字段 | 说明 | 是否必填 | 输入规则 / 展示规则 | 备注 |
|---|---|---:|---|---|
| 组合名称 | 当前商品组合的名称 | 是 | 1-15 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 长度受限，便于展示 |
| 可选单品数量 | 用户可选择的单品数量 | 是 | 正整数；必须大于 0；且不得大于当前组合下的单品总数 | 例如 10 选 3，填写 3 |
| 单品列表 | 组合内包含的单品列表 | 是 | 至少 1 个单品；最多 99 个单品 | 单品级字段见下文 |

控制关系说明：
- `适用商品组合` 至少配置 1 个
- 每个组合下的 `单品列表` 至少配置 1 个单品
- `可选单品数量` 不能大于当前组合下的单品总数

##### 5.2.2.2 单品列表

每个单品至少包含以下字段：

| 字段 | 说明 | 是否必填 | 输入规则 / 展示规则 | 备注 |
|---|---|---:|---|---|
| 单品名称 | 单品展示名称 | 是 | 1-15 个 UTF-8 字符；支持中文、英文、数字、空格及常用符号；不允许表情符号和换行 | 长度受限 |
| 单品价格 | 单品价格 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 金额字段 |
| 单品数量 | 单品数量 | 是 | 正整数；必须大于 0；最多 99 | 数量字段 |
| 单品图片 | 单品展示图片 | 否 | 仅支持通过图片上传能力获得的图片链接；推荐 1:1；建议尺寸 1080\*1080；大小不超过 2M；建议透明 PNG 格式；需保留上下左右 120px 透明边距 | 选填扩展项 |
| 小程序 AppID | 单品跳转小程序标识 | 否 | 需填写合法 AppID；与小程序路径成对出现 | 选填扩展项 |
| 小程序路径 | 单品跳转路径 | 否 | 0-200 个字符；与小程序 AppID 成对出现 | 选填扩展项 |

控制关系说明：
- `单品图片`、`小程序 AppID`、`小程序路径` 均属于选填扩展项
- `小程序 AppID` 与 `小程序路径` 必须同时填写或同时不填
- `单品数量` 为正整数，不允许为 0

## 6. 按钮设计

### 6.1 券类型选择页按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 选择满减券 | 进入满减券创建表单 | 页面加载完成后即可点击 | 进入满减券表单，并锁定券类型 |
| 选择兑换券 | 进入兑换券创建表单 | 页面加载完成后即可点击 | 进入兑换券表单，并锁定券类型 |
| 取消 | 返回列表页 | 页面加载完成后即可点击 | 放弃创建流程并返回列表页 |

### 6.2 创建表单页按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 保存草稿 | 暂存当前填写内容 | 页面存在可保存内容时即可点击；即使必填项未填完也允许保存 | 保存当前内容为草稿；不进入审批流；保留在当前页面 |
| 提交审核 | 提交活动创建结果 | 所有必填项完成且校验通过后可点击 | 创建活动并进入审批中；提交成功后按交互规则返回详情页或列表页 |
| 返回类型选择 | 返回券类型选择页 | 页面加载完成后即可点击；若存在未保存更改，点击前需二次确认 | 返回券类型选择页；当前未保存内容不保留 |
| 取消 | 放弃当前创建 | 页面加载完成后即可点击；若存在未保存更改，点击前需二次确认 | 放弃当前创建并返回列表页 |

### 6.3 可选按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 预览 | 预览活动展示效果 | 当公共区基础信息完成后可点击；若页面不需要可视化确认也可不展示 | 预览当前活动的展示效果，不保存内容 |
| 下载模板 | 下载品牌方准备文件模板 | 若产品需要，则在页面展示且随时可点击 | 下载当前页对应的模板文件 |

## 7. 页面规则

1. 商品券名称不能为空。
2. 商品券图片不能为空。
3. 商品券背景图不能为空。
4. 商品券详情图为选填扩展项。
5. 商品券标题文案不能为空。
6. 规则摘要不能为空。
7. 使用模式固定为 `SINGLE`，不允许修改。
8. 进入创建表单后不允许切换券类型。
9. 返回券类型选择页时，不保留当前已填内容。
10. 保存草稿允许跨天恢复。
11. 同一活动同一时间只能有一个草稿。
12. 提交审核前必须完成所有必填项。
13. 创建成功后活动状态进入审批中。

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 商品券名称重复 | 名称已存在 | 提示修改名称 |
| 图片格式不合法 | 图片格式或尺寸不符合要求 | 阻止提交并提示修正 |
| 必填项未填完 | 存在未填写项 | 阻止提交并定位字段 |
| 适用商品组合少于 1 个 | 需至少配置 1 个组合 | 阻止提交 |
| 单品列表为空 | 每个组合至少需要 1 个单品 | 阻止提交 |
| 小程序 AppID 与路径只填其一 | 两个字段需同时填写或同时不填 | 阻止提交 |
| 提交时服务端失败 | 创建失败，请重试 | 保留当前内容或回退草稿状态 |
| 用户返回类型选择页 | 是否放弃当前内容 | 二次确认后返回选择页 |

## 9. 页面交互

1. 用户进入活动新增页，系统先展示券类型选择页。
2. 用户选择券类型后，进入对应创建表单页。
3. 用户填写公共区和对应差异区内容。
4. 用户可先保存草稿，也可直接提交审核。
5. 提交审核前，系统校验必填项、字段格式和字段联动关系。
6. 校验通过后创建活动，并将活动状态置为审批中。
7. 创建成功后返回活动详情页或活动列表页，按产品最终交互确认。
