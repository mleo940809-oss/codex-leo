# 商品券活动管理 - 活动详情页设计稿

**文档版本**：V1.0  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动详情页  
**文档性质**：初始设计稿，后续变更仅通过版本递增方式更新，不直接覆盖本文件

## 1. 设计目标

活动详情页用于完整查看单个商品券活动的基础信息、展示信息、规则摘要、批次概览和操作入口。

本页以只读展示为主，是活动从列表页进入后的核心承载页。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. 活动详情页主要用于查看
5. 编辑入口仅在 `EFFECTIVE` 状态开放
6. 批次管理入口在 `AUDITING` 与 `EFFECTIVE` 状态开放，但能力边界不同
7. `DEACTIVATED` 状态仅允许查看，不允许编辑或批次操作

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动详情页
- 页面职责：
  - 展示活动完整信息
  - 展示活动状态与关键摘要
  - 提供编辑入口
  - 提供批次管理入口
  - 提供失效入口

## 4. 页面结构

建议详情页采用“头部摘要 + Tab 分区”结构：

1. 头部摘要区
2. 基础信息 Tab
3. 活动规则 Tab
4. 展示信息 Tab
5. 批次概览 Tab
6. 操作记录 Tab

## 5. 展示内容

### 5.1 头部摘要区

头部摘要区建议展示：
- 商品券名称
- 商品券ID
- 商品券类型
- 状态
- 优惠规则摘要
- 创建人
- 最后修改人
- 创建时间
- 最后修改时间

### 5.2 基础信息 Tab

| 字段 | 说明 | 展示方式 |
|---|---|---|
| 商品券名称 | 活动名称 | 只读文本 |
| 商品券ID | 活动唯一标识 | 只读文本 |
| 商品券类型 | 满减券 / 兑换券 | 只读文本 |
| 活动有效期 | 活动生效时间范围 | 只读文本 |
| 优惠范围 | 活动适用范围 | 只读文本 |
| 活动说明 | 活动补充说明 | 只读文本 |

### 5.3 活动规则 Tab

| 字段 | 说明 | 展示方式 |
|---|---|---|
| 使用模式 | 固定值 `SINGLE` | 只读文本 |
| 券Code分配模式 | 固定值 `UPLOAD` | 只读文本 |
| 发放方式 | 活动发放规则说明 | 只读文本 |
| 生效规则 | 活动生效限制说明 | 只读文本 |

### 5.4 展示信息 Tab

| 字段 | 说明 | 展示方式 |
|---|---|---|
| 活动主图 | 活动展示图片 | 图片预览 |
| 活动标题文案 | 页面展示标题 | 只读文本 |
| 活动副标题 | 辅助展示文案 | 只读文本 |
| 规则摘要 | 前台可读规则概述 | 只读文本 |

### 5.5 批次概览 Tab

批次概览 Tab 用于展示该活动下的批次汇总信息，建议包含：
- 批次数量
- 批次状态统计
- 最近创建批次
- 最近更新时间
- 进入批次管理入口

### 5.6 操作记录 Tab

建议展示：
- 创建记录
- 编辑记录
- 失效记录
- 批次关键动作记录

## 6. 按钮设计

| 按钮 | 作用 | 适用状态 | 说明 |
|---|---|---|---|
| 返回 | 返回列表页 | 全部状态 | 回到活动列表 |
| 编辑 | 进入编辑页 | 仅 `EFFECTIVE` | 修改活动基础配置 |
| 批次管理 | 进入批次管理页 | `AUDITING`、`EFFECTIVE` | `AUDITING` 仅查看/预配置；`EFFECTIVE` 支持完整管理 |
| 失效 | 终止活动继续生效 | 仅 `EFFECTIVE` | 失效后活动进入终态 |

## 7. 页面规则

1. 详情页为只读查看页，不在此页直接修改活动基础信息
2. `EFFECTIVE` 状态开放编辑入口
3. `AUDITING` 状态开放批次管理入口，但仅支持查看和预配置
4. `DEACTIVATED` 状态不允许编辑或批次操作
5. 活动详情页应完整展示活动的关键基础信息和展示信息
6. 批次概览仅做汇总展示，不替代批次管理页

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 活动不存在 | 数据不存在或已删除 | 返回空态或错误页 |
| 无权限访问 | 无查看权限 | 按权限处理 |
| 状态加载失败 | 状态获取失败 | 提示重试 |
| 批次概览数据为空 | 当前无批次数据 | 展示空状态 |

## 9. 页面交互

1. 用户从列表页进入活动详情页。
2. 系统加载活动头部摘要和各 Tab 内容。
3. 用户可切换不同 Tab 查看活动详情。
4. 用户可从详情页进入编辑页或批次管理页。
5. 用户点击失效后，系统弹出二次确认。
