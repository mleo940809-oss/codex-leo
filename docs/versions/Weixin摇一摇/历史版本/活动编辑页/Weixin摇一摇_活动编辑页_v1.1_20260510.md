# 商品券活动管理 - 活动编辑页设计稿

**文档版本**：V1.1  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动编辑页  
**文档性质**：修订版，基于“编辑 = 草稿核对 / 已提交未进行活动修订”的生命周期定义调整

## 1. 设计目标

活动编辑页用于对草稿活动、以及已提交但尚未进入执行阶段的活动进行修订和核对，修订结果仍属于生效前调整，不直接作用于已生效活动。

本页不承接生效中的活动修改，生效中的修改将由活动修改页单独承担。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. 编辑动作仅允许在草稿或未进入执行阶段的活动上执行
5. 编辑结果仅用于生效前修订，不影响历史已发券
6. `EFFECTIVE` 状态下不使用本页
7. `DEACTIVATED` 状态下不使用本页

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动编辑页
- 页面职责：
  - 核对草稿内容
  - 修订已提交但未进入执行阶段的活动
  - 补全未完成字段
  - 调整生效前的展示和规则配置

## 4. 页面结构

建议编辑页采用单页表单结构，按信息层级分区展示：

1. 基础信息
2. 活动规则
3. 展示信息
4. Code 配置
5. 保存确认

## 5. 字段设计

### 5.1 基础信息

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 商品券名称 | 活动名称 | 是 | 文本 | 可补全或修订 |
| 商品券ID | 活动唯一标识 | 否 | 只读 | 草稿阶段可为空，提交后生成 |
| 商品券类型 | 满减券 / 兑换券 | 否 | 只读 | 创建后不改 |
| 活动有效期 | 活动生效时间范围 | 是 | 时间范围 | 生效前可调整 |
| 优惠范围 | 活动适用范围 | 是 | 下拉选择 | 生效前可调整 |
| 活动说明 | 活动补充说明 | 是 | 多行文本 | 可修改 |

### 5.2 活动规则

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 使用模式 | 固定值 `SINGLE` | 否 | 只读 | 系统固定值 |
| 券Code分配模式 | 固定值 `UPLOAD` | 否 | 只读 | 系统固定值 |
| 发放方式 | 活动发放规则说明 | 是 | 配置项 | 生效前可调整 |
| 生效规则 | 活动生效限制说明 | 是 | 配置项 | 需与审批流一致 |

### 5.3 展示信息

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 活动主图 | 活动展示图片 | 是 | 图片上传 | 可替换 |
| 活动标题文案 | 页面展示标题 | 是 | 文本 | 用于列表和详情展示 |
| 活动副标题 | 辅助展示文案 | 是 | 文本 | 可选 |
| 规则摘要 | 前台可读规则概述 | 是 | 多行文本 | 用于辅助理解活动内容 |

### 5.4 Code 配置

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| Code 上传方式 | 固定为预上传 | 否 | 只读 | 固定为 `UPLOAD` |
| Code 文件 | 已上传或待补充的 Code 文件 | 视规则而定 | 文件上传 | 用于补全草稿或修订 |
| Code 校验结果 | 文件合法性校验结果 | 自动生成 | 展示项 | 保存前需确认 |

## 6. 按钮设计

### 6.1 页面底部按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 保存修改 | 保存当前编辑内容 | 仅保存生效前修订 |
| 取消 | 放弃当前修改 | 返回上一页 |

### 6.2 可选按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 预览 | 预览编辑后的展示效果 | 若页面需要可视化确认，可开放 |
| 恢复原值 | 回退本次未保存修改 | 便于减少误操作 |

## 7. 页面规则

1. 草稿活动允许进入编辑页继续补全
2. 已提交但未进入执行阶段的活动允许进入编辑页修订
3. `EFFECTIVE` 状态不使用本页
4. `DEACTIVATED` 状态不使用本页
5. 商品券类型、使用模式、Code 分配模式为系统固定值，不允许修改
6. 保存修改前必须完成必填项校验
7. 编辑后的结果仅影响生效前的最终提交内容

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非草稿/未生效状态访问编辑页 | 当前状态不可编辑 | 阻止进入或只读展示 |
| 必填项未填完 | 存在未填写项 | 阻止保存并定位字段 |
| 修改内容与服务端规则冲突 | 保存失败 | 提示并保留当前草稿 |
| 用户取消修改 | 是否放弃当前修改 | 二次确认后返回上一页 |

## 9. 页面交互

1. 用户从列表页或详情页进入编辑页。
2. 系统加载当前草稿或未生效活动的可编辑信息。
3. 用户修订允许编辑的字段。
4. 用户点击 `保存修改` 后，系统执行校验。
5. 校验通过后保存修订结果，仍保留在生效前流程中。
