# 商品券活动管理 - 活动编辑页设计稿

**文档版本**：V1.0  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动编辑页  
**文档性质**：初始设计稿，后续变更仅通过版本递增方式更新，不直接覆盖本文件

## 1. 设计目标

活动编辑页用于对已创建的商品券活动进行基础配置调整，编辑结果仅影响后续新发券，不影响历史已发券。

本页仅描述编辑阶段的规则，不描述新增阶段的创建初始化逻辑。新增阶段将另行输出独立页面设计稿。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. 编辑动作仅允许在 `EFFECTIVE` 状态执行
5. 编辑后的内容仅影响后续新发券，不影响历史已发券
6. `DEACTIVATED` 状态下不允许编辑

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动编辑页
- 页面职责：
  - 修改活动基础配置
  - 修改活动展示信息
  - 维护编辑后的业务口径
  - 提供保存修改和取消退出能力

## 4. 页面结构

建议编辑页采用单页表单结构，按信息层级分区展示：

1. 基础信息
2. 活动规则
3. 展示信息
4. Code 配置
5. 修改确认

## 5. 字段设计

### 5.1 基础信息

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 商品券名称 | 活动名称 | 是 | 文本 | 可修改展示名称 |
| 商品券ID | 活动唯一标识 | 否 | 只读 | 系统生成 |
| 商品券类型 | 满减券 / 兑换券 | 否 | 只读 | 创建后不改 |
| 活动有效期 | 活动生效时间范围 | 视规则而定 | 时间范围 | 是否允许调整由业务规则控制 |
| 优惠范围 | 活动适用范围 | 视规则而定 | 下拉选择 | 可能影响后续发券范围 |
| 活动说明 | 活动补充说明 | 是 | 多行文本 | 内部备注可修改 |

### 5.2 活动规则

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 使用模式 | 固定值 `SINGLE` | 否 | 只读 | 系统固定值 |
| 券Code分配模式 | 固定值 `UPLOAD` | 否 | 只读 | 系统固定值 |
| 发放方式 | 活动发放规则说明 | 视规则而定 | 配置项 | 需要与概设一致 |
| 生效规则 | 活动生效限制说明 | 视规则而定 | 配置项 | 需要与审批规则一致 |

说明：
- 默认仅开放名称和说明类字段
- 若后续业务需要开放更高风险字段，必须在概设和状态规则中补充限制

### 5.3 展示信息

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 活动主图 | 活动展示图片 | 是 | 图片上传 | 可替换 |
| 活动标题文案 | 页面展示标题 | 是 | 文本 | 用于列表和详情展示 |
| 活动副标题 | 辅助展示文案 | 是 | 文本 | 可选 |
| 规则摘要 | 前台可读规则概述 | 是 | 多行文本 | 用于辅助理解活动内容 |

### 5.4 Code 配置

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| Code 上传方式 | 固定为预上传 | 否 | 只读 | 固定为 `UPLOAD` |
| Code 文件 | 已上传或待替换的 Code 文件 | 视规则而定 | 文件上传 | 仅在允许范围内可替换 |
| Code 校验结果 | 文件合法性校验结果 | 自动生成 | 展示项 | 编辑保存前需确认 |

## 6. 按钮设计

### 6.1 页面底部按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 保存修改 | 保存当前编辑内容 | 保存后仅影响后续新发券 |
| 取消 | 放弃当前修改 | 返回详情页或列表页 |

### 6.2 可选按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 预览 | 预览编辑后的展示效果 | 若页面需要可视化确认，可开放 |
| 恢复原值 | 回退本次未保存修改 | 便于减少误操作 |

## 7. 页面规则

1. 仅 `EFFECTIVE` 状态允许进入编辑页并保存修改
2. `DEACTIVATED` 状态不允许编辑
3. 商品券类型、使用模式、Code 分配模式为系统固定值，不允许修改
4. 编辑后的结果仅影响后续新发券，不影响历史已发券
5. 若某些字段存在更严格的可编辑边界，应在字段级规则中进一步限制
6. 保存修改前必须完成必填项校验

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非 `EFFECTIVE` 状态访问编辑页 | 当前状态不可编辑 | 阻止进入或只读展示 |
| 必填项未填完 | 存在未填写项 | 阻止保存并定位字段 |
| 修改内容与服务端规则冲突 | 保存失败 | 提示并保留当前草稿 |
| 用户取消修改 | 是否放弃当前修改 | 二次确认后返回上一页 |

## 9. 页面交互

1. 用户从详情页或列表页进入编辑页。
2. 系统加载当前活动的可编辑信息。
3. 用户修改允许编辑的字段。
4. 用户点击 `保存修改` 后，系统执行校验。
5. 校验通过后保存修改结果，并返回详情页或列表页，按最终交互定义。
