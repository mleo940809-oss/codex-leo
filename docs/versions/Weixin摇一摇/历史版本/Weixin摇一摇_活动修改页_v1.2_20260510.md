# Weixin摇一摇 - 活动修改页设计稿

**文档版本**：V1.2  
**创建日期**：2026-05-10  
**适用范围**：Weixin摇一摇需求目录下的活动修改页  
**文档性质**：修订版，明确生效后活动的低风险展示信息修订规则

## 1. 设计目标

活动修改页用于对已经 `EFFECTIVE` 的活动进行低风险修订。页面支持展示当前活动的完整配置快照，并仅允许修改不影响券规则和批次执行结果的展示类字段。修改结果仅影响后续新发券，不影响历史已发券。

本页不承接草稿核对，不承接 `AUDITING` 阶段修订，也不承接 `DEACTIVATED` 状态活动操作。`Code` 文件上传与校验统一归入批次管理页。本页只承接活动层低风险展示修订，不承担批次层配置、Code 上传和发放控制；修改后的结果以详情页快照和后续发券效果为准。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券 `Code` 分配模式固定为 `UPLOAD`
4. 修改动作仅允许在 `EFFECTIVE` 状态执行
5. 修改结果仅影响后续新发券，不影响历史已发券
6. `AUDITING` 与 `DEACTIVATED` 状态下不使用本页
7. 本页只允许修改低风险字段，高风险字段只读展示

## 3. 页面定位

- 一级模块：Weixin摇一摇
- 二级页面：活动修改页
- 页面职责：
  - 展示当前活动的完整配置快照
  - 仅修改展示类、文案类、图片类等低风险字段
  - 为用户提供上下文，便于判断修改内容

## 4. 页面结构

建议修改页采用单页表单结构，按信息层级划分为以下区域：

1. 基础信息只读区
2. 高风险配置只读区
3. 低风险可编辑区
4. 修改确认

说明：
- 高风险字段展示当前值，但不可编辑
- 低风险字段允许编辑，且沿用新增页中的输入规范
- 本页不出现 `Code` 配置区

## 5. 字段设计

### 5.1 基础信息只读区

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|
| 商品券ID | 活动唯一标识 | 否 | 只读文本 | 系统生成，提交后不可改 |
| 商品券类型 | 满减券 / 兑换券 | 否 | 只读文本 | 创建后固定 |
| 使用模式 | 固定值 `SINGLE` | 否 | 只读文本 | 系统固定值 |
| 券Code分配模式 | 固定值 `UPLOAD` | 否 | 只读文本 | 系统固定值 |

### 5.2 高风险配置只读区

以下字段仅展示当前配置值，不允许在本页编辑。

#### 5.2.1 满减券高风险配置只读区

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |

#### 5.2.2 兑换券高风险配置只读区

| 字段 | 说明 | 是否可编辑 | 类型 | 备注 |
|---|---|---:|---|---|

| 适用商品组合 | 可兑换商品组合配置 | 否 | 组合配置 | 仅展示当前值 |
| 组合名称 | 当前商品组合名称 | 否 | 文本 | 仅展示当前值 |
| 可选单品数量 | 用户可选择的单品数量 | 否 | 整数 | 仅展示当前值 |
| 单品列表 | 组合内包含的单品列表 | 否 | 列表 | 仅展示当前值 |

| 单品数量 | 单品数量 | 否 | 整数 | 仅展示当前值 |

| 小程序路径 | 单品跳转路径 | 否 | 文本 | 仅展示当前值 |

### 5.3 低风险可编辑区

以下字段允许在修改页中编辑，且字段规则与新增页保持一致。

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 商品券图片 | 商品券展示图片 | 是 | 仅支持图片上传；建议 1:1；建议尺寸 1080×1080；大小不超过 2M；建议 PNG；需保留上下左右 120px 安全边距 | 请上传商品券图片，建议 1:1，1080×1080 像素，PNG 格式，大小不超过 2M |
| 商品券背景图 | 商品券背景图片 | 是 | 仅支持图片上传；建议宽高比 65:77；建议尺寸 1170×1326；大小不超过 2M；建议 JPG/PNG | 请上传商品券背景图，建议宽高比 65:77，1170×1326 像素，JPG/PNG 格式，大小不超过 2M |
| 商品券详情图 | 商品券详情图列表 | 是 | 最多 8 张；每张建议宽高比 65:77；建议尺寸 1170×1326；大小不超过 2M；建议 JPG/PNG | 最多可上传 8 张详情图，每张建议宽高比 65:77，1170×1326 像素，JPG/PNG 格式，大小不超过 2M |
| 商品券标题文案 | 页面展示标题 | 是 | 3-20 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行；首尾空格自动去除 | 请输入标题文案，3-20 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 商品券副标题 | 辅助展示文案 | 是 | 0-30 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入副标题，0-30 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 规则摘要 | 前台可读规则概述 | 是 | 0-200 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入规则摘要，0-200 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |

说明：
- 低风险可编辑区只承载展示类、文案类、图片类字段。
- 这些字段的输入规则、图片规格、长度限制和提示文案，均与新增页保持一致。
- 低风险字段修改后，仅影响后续新发券，不影响历史已发券。

## 6. 按钮设计

### 6.1 页面底部按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 保存修改 | 保存当前编辑内容 | 页面存在可保存变更且校验通过时可点击 | 保存当前修改结果，仅影响后续新发券，并保留在当前流程中 |
| 取消 | 放弃当前修改 | 页面加载完成后可点击；若存在未保存变更，点击前需二次确认 | 放弃当前修改并返回上一页 |

## 7. 页面规则

1. 仅 `EFFECTIVE` 状态允许进入修改页并保存修改。
2. `AUDITING` 与 `DEACTIVATED` 状态不使用本页。
3. 商品券类型、使用模式、券 `Code` 分配模式均为系统固定值，不允许修改。
4. 高风险字段仅作只读展示，不进入本页编辑动作。
5. 低风险字段允许编辑，且修改后只影响后续新发券。
6. 保存修改前必须完成必填项校验。
7. 若某些字段存在更严格的可编辑边界，应在字段级规则中进一步限制。

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非 `EFFECTIVE` 状态访问修改页 | 当前状态不可修改 | 阻止进入或只读展示 |
| 必填项未填完 | 存在未填写项 | 阻止保存并定位字段 |
| 图片格式不合法 | 图片格式或尺寸不符合要求 | 阻止保存并提示修正 |
| 修改内容与服务端规则冲突 | 保存失败 | 提示并保留当前草稿内容 |
| 用户取消修改 | 是否放弃当前修改 | 二次确认后返回上一页 |

## 9. 页面交互

1. 用户从列表页或详情页进入修改页。
2. 系统加载当前活动的只读快照与可编辑字段。
3. 用户仅修改低风险字段。
4. 用户点击 `保存修改` 后，系统执行校验。
5. 校验通过后保存修改结果，并返回详情页或列表页，按最终交互定义。
