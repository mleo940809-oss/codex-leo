# 商品券活动管理 - 活动新增页设计稿

**文档版本**：V1.1  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动新增页  
**文档性质**：修订版，基于“新增 = 从零创建活动”的生命周期定义调整

## 1. 设计目标

活动新增页用于创建新的商品券活动，从券类型选择开始，逐步完成活动基础信息、规则信息、展示信息和 Code 配置，最终生成待审核活动。

本页仅负责“从无到有”的创建流程，不承接生效前修订，也不承接生效后修改。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. `SINGLE` 与 `UPLOAD` 均为系统固定属性，不作为用户选择项
5. 新建活动后进入审批流程，初始状态为 `AUDITING`
6. 新增页只负责创建，不负责已存在活动的修订
7. 新增流程采用“两段式”：
   - 第一步：选择券类型
   - 第二步：进入对应表单
8. 进入创建表单后，不允许切换券类型；如需切换，必须返回券类型选择页重新开始
9. 返回券类型选择页时，不保留当前已填内容
10. 允许保存草稿，且草稿以活动为单位保存
11. 每个活动同一时间只能有一个草稿

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动新增页
- 页面职责：
  - 选择券类型
  - 创建新活动
  - 录入活动基础信息
  - 配置活动规则
  - 配置展示信息
  - 初始化 Code 配置

## 4. 页面结构

建议新增页采用“两段式”结构：

### 4.1 券类型选择页

先选择：
- 满减券
- 兑换券

### 4.2 创建表单页

按信息层级分区展示：
1. 基础信息
2. 活动规则
3. 展示信息
4. Code 配置
5. 提交确认

## 5. 字段设计

### 5.1 基础信息

| 字段 | 说明 | 是否必填 | 类型 | 备注 |
|---|---|---:|---|---|
| 商品券名称 | 新建活动的名称 | 是 | 文本 | 用于列表和详情展示 |
| 商品券类型 | 满减券 / 兑换券 | 是 | 只读 | 在首步已确定 |
| 活动有效期 | 活动可生效的时间范围 | 是 | 时间范围 | 用于限制活动生命周期 |
| 优惠范围 | 活动适用范围 | 是 | 下拉选择 | 如门店、商品、渠道等 |
| 活动说明 | 活动补充说明 | 否 | 多行文本 | 用于内部备注 |

### 5.2 活动规则

| 字段 | 说明 | 是否必填 | 类型 | 备注 |
|---|---|---:|---|---|
| 使用模式 | 固定值 `SINGLE` | 是 | 只读 | 不允许修改 |
| 券Code分配模式 | 固定值 `UPLOAD` | 是 | 只读 | 品牌方预上传 Code |
| 发放方式 | 活动发放规则说明 | 是 | 配置项 | 具体配置按概设定义 |
| 生效规则 | 活动生效限制说明 | 是 | 配置项 | 需与审批流一致 |

### 5.3 展示信息

| 字段 | 说明 | 是否必填 | 类型 | 备注 |
|---|---|---:|---|---|
| 活动主图 | 活动展示图片 | 否 | 图片上传 | 可选 |
| 活动标题文案 | 页面展示标题 | 是 | 文本 | 用于列表摘要和活动详情展示 |
| 活动副标题 | 辅助展示文案 | 否 | 文本 | 可用于营销补充信息 |
| 规则摘要 | 前台可读规则概述 | 是 | 多行文本 | 用于辅助理解活动内容 |

### 5.4 Code 配置

| 字段 | 说明 | 是否必填 | 类型 | 备注 |
|---|---|---:|---|---|
| Code 上传方式 | 固定为预上传 | 是 | 只读 | 固定为 `UPLOAD` |
| Code 文件 | 预上传的券 Code 文件 | 视规则而定 | 文件上传 | 由品牌方提供 |
| Code 校验结果 | 文件合法性校验结果 | 自动生成 | 展示项 | 校验通过后才可提交 |

## 6. 按钮设计

### 6.1 券类型选择页按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 选择满减券 | 进入满减券创建表单 | 作为新建起点 |
| 选择兑换券 | 进入兑换券创建表单 | 作为新建起点 |
| 取消 | 返回列表页 | 放弃创建流程 |

### 6.2 创建表单页按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 保存草稿 | 暂存当前填写内容 | 草稿按活动保存 |
| 提交审核 | 提交活动创建结果 | 创建后进入 `AUDITING` |
| 返回类型选择 | 返回券类型选择页 | 不保留当前内容 |
| 取消 | 放弃当前创建 | 返回列表页 |

### 6.3 可选按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 预览 | 预览活动展示效果 | 若页面需要可视化确认，可开放 |
| 下载模板 | 下载 Code 上传模板 | 便于品牌方准备文件 |

## 7. 页面规则

1. 商品券名称不能为空，且需具备唯一性或可区分性要求
2. 商品券类型仅能在 `满减券` 与 `兑换券` 中选择
3. `使用模式` 固定展示为 `SINGLE`
4. `券Code分配模式` 固定展示为 `UPLOAD`
5. 进入创建表单后不允许切换券类型
6. 返回券类型选择页时，不保留当前已填内容
7. Code 文件必须通过校验后才允许提交
8. 保存草稿允许跨天恢复
9. 同一活动同一时间只能有一个草稿
10. 提交审核前必须完成所有创建必填项
11. 创建成功后活动状态进入 `AUDITING`

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 商品券名称重复 | 名称已存在 | 提示修改名称 |
| Code 文件格式错误 | 上传文件不合法 | 阻止提交并提示修正 |
| 必填项未填完 | 存在未填写项 | 阻止提交并定位字段 |
| 提交时服务端失败 | 创建失败，请重试 | 保留当前内容或回退草稿状态 |
| 用户返回类型选择页 | 是否放弃当前内容 | 二次确认后返回选择页 |

## 9. 页面交互

1. 用户进入活动新增页，系统先展示券类型选择页。
2. 用户选择券类型后，进入对应创建表单页。
3. 用户填写基础信息、规则信息、展示信息和 Code 配置。
4. 用户可先保存草稿，也可直接提交审核。
5. 提交审核前，系统校验必填项和 Code 文件合法性。
6. 校验通过后创建活动，并将活动状态置为 `AUDITING`。
7. 创建成功后返回活动详情页或活动列表页，按产品最终交互确认。
