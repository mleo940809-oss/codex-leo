# Weixin摇一摇 - 活动编辑页设计稿

**文档版本**：V1.5  
**创建日期**：2026-05-10  
**适用范围**：Weixin摇一摇需求目录下的活动编辑页  
**文档性质**：修订版，明确编辑页字段全集与字段规则，不再以引用方式描述

## 1. 设计目标

活动编辑页用于对草稿活动，以及已提交但尚未进入执行阶段的活动进行修订和核对。修订结果属于生效前调整，不直接作用于已生效活动。

本页不承接生效中的活动修改，生效中的修改由活动修改页单独承担。本页不承接 Code 配置，Code 文件上传统一归入批次管理页。本页只处理活动层的生效前修订，不承担批次层的预算、门店、Code 和发放动作；编辑完成后的活动快照仍以详情页为准。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券 Code 分配模式固定为 `UPLOAD`
4. 编辑页只处理草稿核对与已提交但未进入执行阶段的修订
5. `AUDITING` 状态下，如活动尚未进入执行动作，可通过本页进行生效前修订
6. 编辑结果仅用于生效前修订，不影响已生效活动
7. `EFFECTIVE` 状态下不使用本页
8. `DEACTIVATED` 状态下不使用本页
9. Code 文件上传属于批次管理页，不属于本页

## 3. 页面定位

- 一级模块：Weixin摇一摇
- 二级页面：活动编辑页
- 页面职责：
  - 核对草稿内容
  - 修订已提交但未进入执行阶段的活动
  - 补全未完成字段
  - 调整生效前的展示和规则配置

## 4. 页面结构

建议编辑页采用单页表单结构，按信息层级分区展示：

1. 基础信息
2. 公共字段区
3. 满减券差异区
4. 兑换券差异区
5. 编辑确认

## 5. 字段设计

### 5.1 基础信息

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 商品券ID | 活动唯一标识 | 否 | 草稿阶段可为空，提交后生成；提交后只读 | 当前活动唯一标识，提交后自动生成 |
| 商品券类型 | 满减券 / 兑换券 | 否 | 只读展示，不可修改 | 当前券类型固定，不可修改 |

### 5.2 公共字段区

以下字段在编辑页中完整展开，字段规则与新增页一致。编辑页不写“引用新增页”字样，直接展示全部规则。

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 商品券名称 | 活动名称 | 是 | 3-15 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行；首尾空格自动去除 | 请输入商品券名称，3-15 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 商品券图片 | 商品券展示图片 | 是 | 仅支持图片上传；建议 1:1；建议尺寸 1080×1080；大小不超过 2M；建议 PNG；需保留上下左右 120px 安全边距 | 请上传商品券图片，建议 1:1，1080×1080 像素，PNG 格式，大小不超过 2M |
| 商品券背景图 | 商品券背景图片 | 是 | 仅支持图片上传；建议宽高比 65:77；建议尺寸 1170×1326；大小不超过 2M；建议 JPG/PNG | 请上传商品券背景图，建议宽高比 65:77，1170×1326 像素，JPG/PNG 格式，大小不超过 2M |
| 商品券详情图 | 商品详情图列表 | 是 | 最多 8 张；每张建议宽高比 65:77；建议尺寸 1170×1326；大小不超过 2M；建议 JPG/PNG | 最多可上传 8 张详情图，每张建议宽高比 65:77，1170×1326 像素，JPG/PNG 格式，大小不超过 2M |
| 商品券标题文案 | 页面展示标题 | 是 | 3-20 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行；首尾空格自动去除 | 请输入标题文案，3-20 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 商品券副标题 | 辅助展示文案 | 是 | 0-30 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入副标题，0-30 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 规则摘要 | 前台可读规则概述 | 是 | 0-200 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入规则摘要，0-200 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 使用模式 | 固定值 `SINGLE` | 否 | 只读展示，不可修改 | 当前使用模式固定为 SINGLE，不可修改 |

#### 5.2.1 公共字段控制关系

- 商品券名称、商品券图片、商品券背景图、商品券标题文案、规则摘要为公共必填项。
- 商品券详情图为选填扩展项，最多 8 张。
- 使用模式为系统固定值，不允许修改。
- 以上字段的输入规则、图片规格、长度限制和提示文案，均在本页完整定义。

### 5.3 满减券差异区

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 门槛金额 | 满减券触发门槛 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 请输入门槛金额，最多保留 2 位小数，不允许为负数 |
| 减免金额 | 满减券减免金额 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 请输入减免金额，最多保留 2 位小数，不允许为负数 |
| 满减说明 | 满减券补充说明 | 是 | 0-100 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入满减说明，0-100 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |

#### 5.3.1 满减券控制关系

- 门槛金额与减免金额均为必填。
- 两个金额互不自动推导。
- 两个金额仅做独立合法性校验，不做自动换算。
- 若后端接口对金额存在额外限制，以提交时返回结果为准。

### 5.4 兑换券差异区

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 商品原价 | 兑换内容对应原价 | 是 | 以元为单位输入；最多 2 位小数；输入范围 0 到 100000.00；不允许负数和字母 | 请输入商品原价，最多保留 2 位小数，不允许为负数 |
| 适用商品组合 | 可兑换商品组合配置 | 是 | 至少配置 1 个组合；最多配置 50 个组合；每个组合需满足组合级校验 | 请至少配置 1 个商品组合 |
| 兑换说明 | 兑换券补充说明 | 是 | 0-100 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入兑换说明，0-100 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |

#### 5.4.1 适用商品组合

“适用商品组合”为可重复配置区，每个组合至少包含以下字段。

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 组合名称 | 当前商品组合的名称 | 是 | 1-15 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入组合名称，1-15 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 可选单品数量 | 用户可选择的单品数量 | 是 | 正整数；必须大于 0；且不得大于当前组合下的单品总数 | 请输入可选单品数量，必须为正整数，且不能大于当前组合下的单品总数 |
| 单品列表 | 组合内包含的单品列表 | 是 | 至少 1 个单品；最多 99 个单品 | 请至少添加 1 个单品，最多可添加 99 个单品 |

##### 5.4.1.1 适用商品组合控制关系

- 适用商品组合至少配置 1 个。
- 每个组合下的单品列表至少配置 1 个单品。
- 可选单品数量不能大于当前组合下的单品总数。

#### 5.4.2 单品列表

每个单品至少包含以下字段。

| 字段 | 说明 | 是否可编辑 | 输入要求 / 展示要求 | 提示文案 |
|---|---|---:|---|---|
| 单品名称 | 单品展示名称 | 是 | 1-15 个字符；支持中文、英文、数字、空格及常用符号；不支持表情符号和换行 | 请输入单品名称，1-15 个字符，支持中文、英文、数字和常用符号，不支持表情和换行 |
| 单品价格 | 单品价格 | 是 | 以元为单位输入；最多 2 位小数；输入范围大于等于 0；不允许负数和字母 | 请输入单品价格，最多保留 2 位小数，不允许为负数 |
| 单品数量 | 单品数量 | 是 | 正整数；必须大于 0；最多 99 | 请输入单品数量，必须为正整数，且至少为 1 |
| 单品图片 | 单品展示图片 | 是 | 仅支持图片上传；建议 1:1；建议尺寸 1080×1080；大小不超过 2M；建议 PNG | 可选上传单品图片，建议 1:1，1080×1080 像素，PNG 格式，大小不超过 2M |
| 小程序 AppID | 单品跳转小程序标识 | 是 | 需填写合法 AppID；与小程序路径成对出现 | 请输入小程序 AppID，如填写路径则必须同时填写 AppID |
| 小程序路径 | 单品跳转路径 | 是 | 0-200 个字符；与小程序 AppID 成对出现 | 请输入小程序路径，如填写 AppID 则必须同时填写路径 |

##### 5.4.2.1 单品列表控制关系

- 单品图片、小程序 AppID、小程序路径均属于选填扩展项。
- 小程序 AppID 与小程序路径必须同时填写或同时不填。
- 单品数量为正整数，不允许为 0。

### 5.5 编辑状态控制

| 状态 | 是否允许进入编辑页 | 是否允许保存修改 | 可编辑范围 |
|---|---|---:|---|
| 草稿 | 是 | 是 | 基础信息、公共字段区、满减券差异区、兑换券差异区均可编辑，固定值除外 |
| `AUDITING` 且未进入执行阶段 | 是 | 是 | 基础信息、公共字段区、满减券差异区、兑换券差异区均可编辑，固定值除外 |
| `EFFECTIVE` | 否 | 否 | 不适用本页 |
| `DEACTIVATED` | 否 | 否 | 不适用本页 |

说明：
- 本页不承接 `Code` 上传或校验。
- 本页同名字段的字段规则，均在本页完整展开，不再通过引用方式说明。

## 6. 按钮设计

### 6.1 页面底部按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 保存修改 | 保存当前编辑内容 | 页面存在可保存变更且校验通过时可点击 | 保存当前修订，仍保留在生效前流程中 |
| 取消 | 放弃当前修改 | 页面加载完成后可点击；若存在未保存变更，需二次确认 | 返回上一页 |

## 7. 页面规则

1. 草稿活动允许进入编辑页继续补全。
2. 已提交但未进入执行阶段的活动允许进入编辑页修订。
3. `AUDITING` 但未进入执行阶段的活动允许通过本页进行生效前修订。
4. `EFFECTIVE` 状态不使用本页。
5. `DEACTIVATED` 状态不使用本页。
6. 商品券类型、使用模式为系统固定值，不允许修改。
7. `Code` 文件上传与校验不属于本页职责。
8. 保存修改前必须完成必填项校验。
9. 编辑后的结果仅影响生效前的最终提交内容。

## 8. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非草稿/未生效状态访问编辑页 | 当前状态不可编辑 | 阻止进入或只读展示 |
| 必填项未填完 | 存在未填写项 | 阻止保存并定位字段 |
| 修改内容与服务端规则冲突 | 保存失败 | 提示并保留当前草稿 |
| 用户取消修改 | 是否放弃当前修改 | 二次确认后返回上一页 |

## 9. 页面交互

1. 用户从列表页或详情页进入编辑页。
2. 系统加载当前草稿或未进入执行阶段活动的可编辑信息。
3. 用户修订允许编辑的字段。
4. 用户点击 `保存修改` 后，系统执行校验。
5. 校验通过后保存修订结果，仍保留在生效前流程中。
