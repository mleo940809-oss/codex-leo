# 商品券活动管理 - 活动列表页设计稿

**文档版本**：V1.1  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的活动列表页  
**文档性质**：修订版，基于 V1.0 增补 `预配置` 定义与批次管理边界说明

## 1. 设计目标

活动列表页作为商品券活动管理的统一入口，承载活动的检索、查看、编辑入口、批次入口和失效入口。

本页仅管理活动级能力，不展开后端接口细节。后端接口、状态流转和调用顺序放入概设与流程图中体现。

## 2. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券Code分配模式固定为 `UPLOAD`
4. `SINGLE` 与 `UPLOAD` 均为系统固定属性，不作为列表查询条件，不在列表页展示
5. 活动支持编辑，但仅在 `EFFECTIVE` 状态下开放
6. 编辑后的内容仅影响后续新发券，不影响历史已发券
7. 批次管理在 `AUDITING` 状态下允许进入，但仅支持查看和预配置，不允许发放、核销、失效等动作
8. 已失效活动不允许批次管理

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：活动列表页
- 页面职责：
  - 展示活动列表
  - 提供筛选条件
  - 进入活动详情
  - 进入批次管理
  - 执行活动失效
  - 进入活动新增/编辑页

## 6. 功能按钮

### 6.1 顶部按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 新增活动 | 创建新的商品券活动 | 进入活动新增页 |

### 6.2 行内按钮

| 按钮 | 作用 | 适用状态 | 说明 |
|---|---|---|---|
| 查看 | 查看活动详情 | 全部状态 | 进入活动详情页 |
| 编辑 | 修改活动基础配置 | 仅 `EFFECTIVE` | 修改仅影响后续新发券 |
| 批次管理 | 进入活动批次管理页 | `AUDITING`、`EFFECTIVE` | `AUDITING` 仅允许查看和预配置；`EFFECTIVE` 支持完整管理；`DEACTIVATED` 不可用 |
| 失效 | 终止活动继续生效 | 仅 `EFFECTIVE` | 失效后活动进入终态 |

### 6.3 批次管理权限说明

- `AUDITING` 状态下，允许进入批次管理页，但仅支持查看批次信息和预配置批次基础内容
- `AUDITING` 状态下，不允许执行发放、核销、失效、暂停等影响券生命周期的操作
- `EFFECTIVE` 状态下，允许批次完整管理
- `DEACTIVATED` 状态下，不允许进入批次管理页进行操作

### 6.4 预配置定义

`预配置` 指在活动审批中提前完成批次的准备性信息维护，仅用于后续执行前的准备，不产生实际发放效果和状态流转结果。

`预配置` 的范围仅限于以下动作：

1. 新建批次草稿
2. 编辑批次基础信息
3. 预填发放所需的前置参数
4. 上传待用 Code 的准备动作
5. 预览与校验字段完整性、格式和后续执行条件

`预配置` 不包含以下动作：

1. 发放
2. 核销
3. 失效
4. 暂停
5. 退券
6. 正式激活执行
7. 对外可见的生效流转
8. 影响库存或发券结果的操作

## 7. 状态规则

| 状态 | 查看 | 编辑 | 批次管理 | 失效 |
|---|---|---|---|---|
| `AUDITING` 审批中 | 可用 | 不可用 | 可用，但仅查看/预配置 | 不可用 |
| `EFFECTIVE` 生效中 | 可用 | 可用 | 可用，支持完整管理 | 可用 |
| `DEACTIVATED` 已失效 | 可用 | 不可用 | 不可用 | 不可用 |

### 7.1 状态补充规则

- 活动仅在 `EFFECTIVE` 状态允许编辑
- 活动编辑后，仅对后续新发券生效，不影响历史已发券
- 活动失效后，不再允许继续发放新的券
- `AUDITING` 状态允许批次预配置，但不允许进入发放执行动作
- `DEACTIVATED` 状态下，批次管理不可用

## 8. 业务规则

1. `使用模式` 固定为 `SINGLE`，不作为筛选条件，也不作为用户可编辑项
2. `券Code分配模式` 固定为 `UPLOAD`，不作为筛选条件，也不作为用户可编辑项
3. 活动仅在 `EFFECTIVE` 状态允许编辑
4. 活动编辑后仅对后续新发券生效，不影响历史已发券
5. 批次管理在 `AUDITING` 状态可进入，但只允许查看和预配置
6. `DEACTIVATED` 状态下，批次管理不可用
7. `失效` 操作只允许在 `EFFECTIVE` 状态执行

## 9. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非 `EFFECTIVE` 状态点击编辑 | 当前状态不可编辑 | 按钮置灰或隐藏 |
| `AUDITING` 状态点击批次管理 | 当前仅支持查看/预配置 | 仅开放批次预配置与查看能力 |
| `DEACTIVATED` 状态点击批次管理 | 当前状态不可操作 | 按钮置灰或隐藏 |
| 无权限用户访问按钮 | 无操作权限 | 按权限隐藏或提示 |
| 查询无结果 | 未找到符合条件的数据 | 展示空状态 |

## 10. 页面交互

1. 用户进入活动列表页，系统默认展示活动列表数据。
2. 用户可通过筛选条件检索活动。
3. 用户点击 `新增活动` 进入新增页。
4. 用户点击 `查看` 进入活动详情页。
5. 用户点击 `编辑` 进入编辑页，仅在 `EFFECTIVE` 状态开放。
6. 用户点击 `批次管理` 进入该活动的批次管理页。
7. 用户点击 `失效` 后，系统弹出二次确认，确认后将活动状态更新为终态。
