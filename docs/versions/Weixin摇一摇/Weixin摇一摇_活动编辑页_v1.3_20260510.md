# Weixin摇一摇 - 活动编辑页设计稿

**文档版本**：V1.3  
**创建日期**：2026-05-10  
**适用范围**：Weixin摇一摇需求目录下的活动编辑页  
**文档性质**：修订版，明确复用新增页字段规则，仅补充编辑页专属规则

## 1. 设计目标

活动编辑页用于对草稿活动，以及已提交但尚未进入执行阶段的活动进行修订和核对。修订结果属于生效前调整，不直接作用于已生效活动。

本页不承接生效中的活动修改，生效中的修改由活动修改页单独承担。本页不承接 Code 配置，Code 文件上传统一归入批次管理页。

## 2. 设计原则

1. 同名字段优先复用活动新增页的字段规则，不重复造轮子。
2. 编辑页只补充“哪些字段可编辑、什么状态可编辑、保存后如何处理”的规则。
3. 只有当编辑页出现新增页没有的字段时，才单独定义新规则。
4. `Code` 相关能力不在编辑页出现。

## 3. 已确认的业务前提

1. 商品券类型仅支持两种：
   - 满减券
   - 兑换券
2. 使用模式固定为 `SINGLE`
3. 券 Code 分配模式固定为 `UPLOAD`
4. 编辑页只处理草稿核对与已提交但未进入执行阶段的修订
5. `AUDITING` 状态下，如活动尚未进入执行动作，可通过本页进行生效前修订
6. 编辑结果仅用于生效前修订，不影响已生效活动
7. `EFFECTIVE` 状态下不使用本页
8. `DEACTIVATED` 状态下不使用本页
9. Code 文件上传属于批次管理页，不属于本页

## 4. 页面定位

- 一级模块：Weixin摇一摇
- 二级页面：活动编辑页
- 页面职责：
  - 核对草稿内容
  - 修订已提交但未进入执行阶段的活动
  - 补全未完成字段
  - 调整生效前的展示和规则配置

## 5. 页面结构

建议编辑页采用单页表单结构，按信息层级分区展示：

1. 基础信息
2. 公共字段复用区
3. 类型差异区复用区
4. 编辑确认

## 6. 字段设计

### 6.1 基础信息

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 商品券ID | 活动唯一标识 | 否 | 编辑页定义 | 草稿阶段可为空，提交后生成 |
| 商品券类型 | 满减券 / 兑换券 | 否 | 编辑页定义 | 创建后不改 |
| 活动有效期 | 活动生效时间范围 | 是 | 编辑页定义 | 生效前可调整 |
| 优惠范围 | 活动适用范围 | 是 | 编辑页定义 | 生效前可调整 |
| 活动说明 | 活动补充说明 | 是 | 编辑页定义 | 可修改 |

### 6.2 公共字段复用区

以下字段直接复用活动新增页的字段规则，包括文本长度、允许字符、图片规格、数量限制、提示文案和校验方式。

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 商品券名称 | 活动名称 | 是 | 复用新增页 | 可补全或修订 |
| 商品券图片 | 商品券展示图片 | 是 | 复用新增页 | 可替换 |
| 商品券背景图 | 商品券背景图片 | 是 | 复用新增页 | 可替换 |
| 商品券详情图 | 商品详情图列表 | 是 | 复用新增页 | 可增删改 |
| 商品券标题文案 | 页面展示标题 | 是 | 复用新增页 | 用于列表和详情展示 |
| 商品券副标题 | 辅助展示文案 | 是 | 复用新增页 | 可选 |
| 规则摘要 | 前台可读规则概述 | 是 | 复用新增页 | 用于辅助理解活动内容 |
| 使用模式 | 固定值 `SINGLE` | 否 | 复用新增页 | 系统固定值 |

说明：
- 以上复用字段的输入规则、图片规格、长度限制和提示文案，均沿用活动新增页定义。
- 编辑页只改变这些字段的可编辑状态，不改变字段本身的校验口径。

### 6.3 类型差异区复用区

以下字段按当前券类型复用活动新增页的规则。

#### 6.3.1 满减券差异区

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 门槛金额 | 满减券触发门槛 | 是 | 复用新增页 | 金额输入规则、提示文案、联动关系均沿用新增页 |
| 减免金额 | 满减券减免金额 | 是 | 复用新增页 | 金额输入规则、提示文案、联动关系均沿用新增页 |
| 满减说明 | 满减券补充说明 | 是 | 复用新增页 | 文本规则沿用新增页 |

#### 6.3.2 兑换券差异区

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 商品原价 | 兑换内容对应原价 | 是 | 复用新增页 | 金额规则沿用新增页 |
| 适用商品组合 | 可兑换商品组合配置 | 是 | 复用新增页 | 组合数量、单品数量、联动规则沿用新增页 |
| 兑换说明 | 兑换券补充说明 | 是 | 复用新增页 | 文本规则沿用新增页 |

##### 6.3.2.1 适用商品组合

“适用商品组合”为可重复配置区，每个组合至少包含以下字段。字段规则沿用活动新增页。

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 组合名称 | 当前商品组合的名称 | 是 | 复用新增页 | 与新增页一致 |
| 可选单品数量 | 用户可选择的单品数量 | 是 | 复用新增页 | 与新增页一致 |
| 单品列表 | 组合内包含的单品列表 | 是 | 复用新增页 | 与新增页一致 |

##### 6.3.2.2 单品列表

每个单品至少包含以下字段。字段规则沿用活动新增页。

| 字段 | 说明 | 是否可编辑 | 规则来源 | 备注 |
|---|---|---:|---|---|
| 单品名称 | 单品展示名称 | 是 | 复用新增页 | 与新增页一致 |
| 单品价格 | 单品价格 | 是 | 复用新增页 | 与新增页一致 |
| 单品数量 | 单品数量 | 是 | 复用新增页 | 与新增页一致 |
| 单品图片 | 单品展示图片 | 是 | 复用新增页 | 与新增页一致 |
| 小程序 AppID | 单品跳转小程序标识 | 是 | 复用新增页 | 与新增页一致 |
| 小程序路径 | 单品跳转路径 | 是 | 复用新增页 | 与新增页一致 |

### 6.4 编辑状态控制

| 状态 | 是否允许进入编辑页 | 是否允许保存修改 | 可编辑范围 |
|---|---|---:|---|
| 草稿 | 是 | 是 | 基础信息、公共字段复用区、类型差异区均可编辑，固定值除外 |
| `AUDITING` 且未进入执行阶段 | 是 | 是 | 基础信息、公共字段复用区、类型差异区均可编辑，固定值除外 |
| `EFFECTIVE` | 否 | 否 | 不适用本页 |
| `DEACTIVATED` | 否 | 否 | 不适用本页 |

说明：
- 本页不承接 `Code` 上传或校验。
- 本页复用新增页字段规则时，只复用字段格式与校验，不复用新增页的创建流程和状态流转。

## 7. 按钮设计

### 7.1 页面底部按钮

| 按钮 | 作用 | 何时可点击 | 点击效果 |
|---|---|---|---|
| 保存修改 | 保存当前编辑内容 | 页面存在可保存变更且校验通过时可点击 | 保存当前修订，仍保留在生效前流程中 |
| 取消 | 放弃当前修改 | 页面加载完成后可点击；若存在未保存变更，需二次确认 | 返回上一页 |

### 7.2 可选按钮

| 按钮 | 作用 | 说明 |
|---|---|---|
| 预览 | 预览编辑后的展示效果 | 若页面需要可视化确认，可开放 |
| 恢复原值 | 回退本次未保存修改 | 便于减少误操作 |

## 8. 页面规则

1. 草稿活动允许进入编辑页继续补全。
2. 已提交但未进入执行阶段的活动允许进入编辑页修订。
3. `AUDITING` 但未进入执行阶段的活动允许通过本页进行生效前修订。
4. `EFFECTIVE` 状态不使用本页。
5. `DEACTIVATED` 状态不使用本页。
6. 商品券类型、使用模式为系统固定值，不允许修改。
7. `Code` 文件上传与校验不属于本页职责。
8. 保存修改前必须完成必填项校验。
9. 编辑后的结果仅影响生效前的最终提交内容。
10. 编辑页同名字段的字段规则，默认复用活动新增页。

## 9. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非草稿/未生效状态访问编辑页 | 当前状态不可编辑 | 阻止进入或只读展示 |
| 必填项未填完 | 存在未填写项 | 阻止保存并定位字段 |
| 修改内容与服务端规则冲突 | 保存失败 | 提示并保留当前草稿 |
| 用户取消修改 | 是否放弃当前修改 | 二次确认后返回上一页 |

## 10. 页面交互

1. 用户从列表页或详情页进入编辑页。
2. 系统加载当前草稿或未进入执行阶段活动的可编辑信息。
3. 用户修订允许编辑的字段。
4. 用户点击 `保存修改` 后，系统执行校验。
5. 校验通过后保存修订结果，仍保留在生效前流程中。
