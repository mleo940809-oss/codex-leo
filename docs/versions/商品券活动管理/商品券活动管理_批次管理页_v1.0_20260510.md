# 商品券活动管理 - 批次管理页设计稿

**文档版本**：V1.0  
**创建日期**：2026-05-10  
**适用范围**：商品券活动管理模块下的批次管理页  
**文档性质**：初始设计稿，后续变更仅通过版本递增方式更新，不直接覆盖本文件

## 1. 设计目标

批次管理页用于管理某一个商品券活动下的批次信息，承载批次的创建、查看、预配置、发放控制和状态管理。

本页只描述批次管理的页面能力，不展开后端接口实现细节。后端接口流转和生命周期控制放入概设和流程图中体现。

## 2. 已确认的业务前提

1. 批次归属于某一个活动
2. `AUDITING` 状态下允许进入批次管理页，但仅支持查看和预配置
3. `EFFECTIVE` 状态下允许完整批次管理
4. `DEACTIVATED` 状态下不允许批次管理
5. 预配置不等于发放，不触发任何券生命周期动作

## 3. 页面定位

- 一级模块：商品券活动管理
- 二级页面：批次管理页
- 页面职责：
  - 查看活动下批次列表
  - 新建批次草稿
  - 维护批次基础信息
  - 预上传 Code
  - 控制批次发放状态
  - 查看批次操作记录

## 4. 页面结构

建议批次管理页采用“活动摘要 + 批次列表 + 批次详情抽屉/面板”的结构：

1. 活动摘要区
2. 批次列表区
3. 批次详情区
4. Code 管理区
5. 操作记录区

## 5. 展示内容

### 5.1 活动摘要区

建议展示当前活动的基础摘要：
- 商品券名称
- 商品券ID
- 商品券类型
- 状态
- 优惠规则摘要

### 5.2 批次列表区

建议列表字段包括：
- 批次编号
- 批次名称
- 批次状态
- 预计发放时间
- Code 总量
- 已使用量
- 剩余量
- 创建人
- 最后修改人
- 操作

### 5.3 批次详情区

批次详情建议展示：
- 批次名称
- 批次编号
- 关联活动
- 批次状态
- 预计开始时间
- 预计结束时间
- 适用范围
- 批次说明
- Code 配置
- 统计信息

### 5.4 Code 管理区

建议展示：
- Code 上传状态
- Code 文件名
- Code 校验结果
- 上传时间
- 校验时间

## 6. 按钮设计

### 6.1 顶部按钮

| 按钮 | 作用 | 适用状态 | 说明 |
|---|---|---|---|
| 新建批次 | 创建新的批次草稿 | `AUDITING`、`EFFECTIVE` | `AUDITING` 仅允许草稿和预配置 |
| 返回活动详情 | 返回活动详情页 | 全部状态 | 回到上级页面 |

### 6.2 批次行内按钮

| 按钮 | 作用 | 适用状态 | 说明 |
|---|---|---|---|
| 查看 | 查看批次详情 | 全部状态 | 只读查看 |
| 编辑 | 修改批次基础信息 | `AUDITING`、`EFFECTIVE` | 具体可编辑范围由状态控制 |
| 预上传Code | 上传批次待用 Code | `AUDITING`、`EFFECTIVE` | 上传后需校验 |
| 发放 | 开始批次发放 | 仅 `EFFECTIVE` | 触发实际发放动作 |
| 暂停 | 暂停批次发放 | 仅 `EFFECTIVE` | 中止当前发放 |
| 失效 | 结束批次并失效 | 仅 `EFFECTIVE` | 终止批次后续动作 |

## 7. 状态规则

| 活动状态 | 批次管理入口 | 新建批次 | 预配置 | 发放 | 暂停 | 失效 |
|---|---|---|---|---|---|---|
| `AUDITING` 审批中 | 可用 | 可用 | 可用 | 不可用 | 不可用 | 不可用 |
| `EFFECTIVE` 生效中 | 可用 | 可用 | 可用 | 可用 | 可用 | 可用 |
| `DEACTIVATED` 已失效 | 不可用 | 不可用 | 不可用 | 不可用 | 不可用 | 不可用 |

### 7.1 批次状态说明

批次状态建议单独管理，至少包含：
- 草稿
- 预配置完成
- 待发放
- 发放中
- 已暂停
- 已失效
- 已结束

### 7.2 预配置定义

`预配置` 指在活动审批中提前完成批次的准备性信息维护，仅用于后续执行前的准备，不产生实际发放效果和状态流转结果。

`预配置` 可以包含：
- 新建批次草稿
- 编辑批次基础信息
- 填写发放前置参数
- 上传待用 Code
- 预览与校验

`预配置` 不包含：
- 发放
- 核销
- 失效
- 暂停
- 退券

## 8. 页面规则

1. 批次归属于某一个活动，不能脱离活动独立存在
2. `AUDITING` 状态只允许查看与预配置
3. `EFFECTIVE` 状态允许完整批次管理
4. `DEACTIVATED` 状态不允许进入批次管理页操作
5. 预上传 Code 必须通过校验后才能进入下一步
6. 发放、暂停、失效属于批次生命周期动作，仅在 `EFFECTIVE` 下开放

## 9. 异常情况

| 场景 | 提示 | 处理方式 |
|---|---|---|
| 非法状态进入批次管理页 | 当前状态不可操作 | 阻止操作或只读展示 |
| Code 文件不合法 | 上传文件校验失败 | 阻止继续操作 |
| 批次信息缺失 | 批次信息不完整 | 提示补齐 |
| 发放时出现失败 | 发放失败，请重试 | 保留状态并记录失败原因 |

## 10. 页面交互

1. 用户从活动详情页或列表页进入批次管理页。
2. 系统展示当前活动摘要与批次列表。
3. 用户可新建批次草稿或查看既有批次。
4. 在 `AUDITING` 状态下，用户只能进行批次预配置。
5. 在 `EFFECTIVE` 状态下，用户可执行完整批次管理动作。
6. 用户操作完成后，系统刷新批次列表和状态统计。
