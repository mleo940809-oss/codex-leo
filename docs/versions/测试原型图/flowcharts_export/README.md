# 流程图导出说明

本目录含 **10 个** 与 `PRD业务流程图_Mermaid_Weixin摇一摇_v2.20_20260513.md` 对应的 Mermaid 源文件（`.mmd`）。

## 如何查看成图

1. **浏览器（推荐）**  
   打开上一级目录中的  
   `PRD业务流程图_Weixin摇一摇_v2.20_流程图浏览.html`  
   需联网加载 CDN 上的 Mermaid 脚本。可在浏览器中使用「打印 → 另存为 PDF」导出。

2. **Mermaid Live**  
   将某个 `.mmd` 文件内容粘贴到 <https://mermaid.live> ，可导出 **SVG / PNG**。

3. **VS Code**  
   安装 Mermaid 预览类扩展后，打开 `.mmd` 或 Markdown 中的代码块即可预览。

## 与主文档的差异

- `flow10_活动与集成数据关系.mmd`：将「活动层页面 + 批次层页面 → 操作留痕」拆为两条箭头（`P1 --> L` 与 `P2 --> L`），避免部分渲染器对 `P1 & P2 --> L` 语法不兼容。
